# training/observability

## 目的

- 監視と可観測性を中心に、システムの運用課題をエンジニアリングで解決できるようになる

## 構成

- [study/](./study)
  - 座学的に学ぶためのファイルを配置するディレクトリです。
- [workshop/](./workshop)
  - 演習的に学ぶためのファイルを配置するディレクトリです。

それぞれのディレクトリには連番でファイルが配置されています。`workshop`のファイル番号と`study`のファイル番号は内容が対応します。

### 進め方

`workshop`の内容を順番に進めていきながら「総合演習」の完成を目指してください。

`workshop`の演習を効率よく進めるため、あるいは`workshop`の演習による理解を深めるために、対応する`study`の内容を参照することが想定されています。

`workshop`の内容のうち、`(Optional)`と記載されているものは、時間に余裕がある場合に取り組んでください。発展的内容です。取り組むとより深く学ぶことができますが、時間がかかることが予測されます。
