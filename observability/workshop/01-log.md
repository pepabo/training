# ログ

## 2.1. アプリケーションのログを出力してみよう

自分のアプリケーションが適当なタイミングでログを出力するようにしてみましょう。構造化は後でも大丈夫です。
アプリケーションがログを標準出力に出すようにしたら、実際にログを出す様子をkubectlコマンドで確認してみましょう。

## 2.2. ログを収集してみよう

各ノードには、Datadog Agentがインストールされ、ログ収集の設定が有効化されています。
標準出力されたログはすでにDatadog Logsで確認できるようになっているはずです。以下を確認してみましょう。

- 特定の時刻を与えられたら、その時刻に出力されたログを確認できますか？
- 特定のPodに限定して、そのPodが出力したログを確認できますか？

## 2.3. (Optional) 構造化ログを収集・確認してみよう

構造化ログを出力することで、ログの解析が容易になります。例えばJSON形式で情報を構造化しながらログを出力してみましょう。

例えば、次の構造でログを出力してみてください。

```json
{
  "level": "info",
  "message": "Hello, world!",
  "user_id": 12345
}
```
